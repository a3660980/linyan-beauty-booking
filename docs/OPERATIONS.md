# 店家操作與維護

## 每日流程

1. 使用已授權的 LINE 帳號登入店家後台。
2. 查看待確認申請，核對日期、服務、金額、同行或前次服務資格。
3. 確認預約後，系統排程 LINE 成功通知。拒絕／取消會釋出時段並通知。
4. 到店收現金後，填寫實收金額，完成服務時標記「服務完成」。預約成功不代表已付款。
5. 定期檢查通知紀錄；「API 已受理」不代表送達或已讀。封鎖官方帳號者可能收不到訊息，客人仍可查詢我的預約。

## 服務時間與整理

初始服務分鐘為接睫 120、補睫 60、卸除 30、霧眉 180；整理緩衝為 30 分鐘。接睫與霧眉依店家提供的範圍採上限，各款式可在「服務與排班」調整。卸除續接額外保留 30 分鐘；霧眉補色保留 180 分鐘（採 2–3 小時上限）、無創除色 60 分鐘；下睫毛加購增加 30 分鐘，另外再計入客人之間的整理緩衝。

例如 10:00 開始接睫，服務保留到 12:00，整理到 12:30，下一位最早 12:30。本次資料更新會同步已初始化紀錄的補色、除色與下睫毛加購時間，其他設定及既有預約保留。後續可在後台調整各服務時間。

## 行事曆逐日排班

1. 後台開啟「行事曆」，預設顯示月曆，也可切換日／週。
2. 點選日期，或按「新增可預約時間」並選日期。
3. 取消「全天休息」，輸入開始與結束時間；按「新增時間區段」可安排上午、下午或午休，每天最多 5 段。
4. 按「儲存當日排班」，客人可預約的時段立即依當日時間、完整服務與整理時間計算；已被預約的時間不會再提供。
5. 勾選「全天休息」並儲存可關閉該日。已有指定排班時，按「恢復固定排班」可移除當日設定。

固定週班表為選用：不固定營業時，將每週固定排班全部留空並儲存，再使用行事曆逐日開放。未設定的日期不提供預約。當日指定排班優先於固定週班表，單日休息也會覆蓋固定營業時間。

月曆顯示固定／指定排班及時間；修改時若影響待確認或已確認預約，編輯畫面會列出相關客人。這些預約保留，請店家調整安排並聯絡客人。示範排班在同一瀏覽器工作階段可切換到示範預約頁查看；重新整理即重置，不會寫入正式資料。

## 同步到 iPhone 行事曆

1. 使用管理員 LINE 帳號登入正式後台，開啟「行事曆」。
2. 按「同步到 iPhone」→「開啟訂閱」→「加入 iPhone 行事曆」，在 iPhone 完成訂閱。
3. 若在 LINE 內無法加入，使用 Safari 開啟後台；也可按「複製訂閱網址」，在 iPhone「行事曆」App 的行事曆列表選「加入行事曆」→「加入訂閱行事曆」，貼上網址。

這是免費的單向 ICS 訂閱，僅顯示已確認及已完成的預約，範圍為近 30 天至未來 180 天。時段包含完整服務與整理時間；顯示客人姓名、服務、規格、預約編號及店址，不包含電話、備註、LINE 身分或收款資料。取消後會在下一次成功擷取時從訂閱內容移除。空行事曆仍可先訂閱。

新增或修改預約仍需在網站後台處理。iPhone 依行事曆擷取設定定期更新，網站提供的 15 分鐘更新建議不保證被裝置採用；請以後台最新資料為準。[Apple 訂閱操作說明](https://support.apple.com/zh-tw/guide/iphone/iph3d1110d4/ios)。

每位管理員擁有自己的私人連結，可各自訂閱相同店家預約；不要放進公開 GitHub、訊息截圖或公開貼文。連結持有者能讀取預約內容，不需要 LINE 登入。後台可以「停用訂閱」或「重新產生連結」，只影響操作管理員的連結；舊連結隨即失效。請在 iPhone 刪除舊訂閱，使用新連結重新加入；停用不會主動清除裝置已下載的資料。

移除管理員白名單會立即阻擋該帳號的訂閱；若日後重新授權，原連結會恢復，應由該管理員重新產生連結以撤銷舊裝置。輪替 `AUTH_SECRET` 也會讓所有既有連結失效，各管理員須重新取得並訂閱。示範後台不建立私人連結。單次擷取最多提供 2,000 筆，超過時返回暫時不可用而不提供截斷清單，避免裝置誤判大量預約已刪除；需由維護者調整範圍或容量。

## 排班與優惠

- 固定排班可分段，空白為休息；特定日期排班覆蓋週排班。
- 待確認申請占用服務與整理時間。逾時釋出由排程與查詢處理，最長受排程間隔影響。
- 兩人同行霧眉每人 $4,500。兩位使用相同同行預約識別碼，分別安排時段。未建立第二筆關聯預約不能確認優惠。
- 補睫需要原客人前次已完成美睫紀錄，限兩週內原款式；店家輸入核對後的半價金額。補色需要三個月內已完成霧眉紀錄。
- 無創除色由店家審核確認金額。不要把估價當成已收款。
- 手動新增的預約未綁定 LINE，請店家自行聯絡客人。

## 訊息與額度

提醒預設關閉，開啟後由每 10 分鐘排程處理明日前的通知。LINE 輕用量每月有免費訊息上限；可在系統 LINE 通知頁查詢本月剩餘額度，也可在 LINE 官方帳號後台查看用量，不足時關閉提醒、改以人工聯絡或升級方案。LINE API 429 可能代表頻率或額度限制。

失敗通知採退避重試，最多自動嘗試 5 次；後台可重新排程。不同通知種類只建立一次，避免重複確認造成重複推播。

## 匯出與備份

後台現金收款頁可匯出 CSV。下載後保存在私人裝置，禁止提交到公開 GitHub、Issue 或 Actions artifact。

D1 有平台備份／Time Travel，保留期限依方案而定。另可由管理員執行 `wrangler d1 export DB --remote --config .deploy/wrangler.json --output backups/private.sql` 保存至忽略的 backups 目錄；先建立目錄，定期驗證還原流程。不要由公開 CI 上傳 SQL 備份。

## 維護

每月檢查依賴更新與通知失敗。結構更新增加 migration；避免破壞已有預約。回退 Worker 版本不會自動回退 D1 migration。刪除或修正個資前核對申請人身分，保留必要操作紀錄，依店家訂定的保留政策處理。
