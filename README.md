# 琳顏美學 Linyanbeauty｜LINE 預約系統

奶油白、藕粉與深咖啡色的品牌網站。服務包含美睫、卸除、補睫、霧眉及除色；採到店現金付款。客人申請後須由店家確認，才正式成立。

## 已實作

- 手機／桌面品牌首頁、價目表、品牌視覺、預約須知與資料使用說明。
- 霧眉＋睫毛組合：選擇睫毛款式與根數，服務 270 分鐘＋整理 30 分鐘，加購時間另計。
- 後台新增預約直接確認，可搜尋現有客人或輸入新客人的姓名、電話；既有 LINE 綁定只會沿用明確選擇的客人。
- 未綁定客人的新增成功頁自動產生一次性邀請連結與可複製訊息；客戶 LINE 登入、加入好友並確認後，綁定並發送一次確認通知。
- 客戶只看服務開始、結束時間；整理時間僅後台顯示，排程至少保留 30 分鐘。
- 新客戶預約以資料庫佇列通知指定管理員審核，通知收件人保存在私有資料庫，不隨原始碼發布。
- 三步驟預約：服務／加購、日期時段、LINE 身分與聯絡資料。
- 可設定的服務時間、緩衝；行事曆點日期逐日排班，每天最多 5 段時間或全天休息，固定週班表為選用。
- D1 寫入 trigger 防止重複與重疊預約；待確認占位與申請逾時釋出。
- LINE OAuth 身分驗證、好友狀態、管理員白名單、客人自己的預約查詢與取消。
- 日／週／月行事曆、預約審核、完成／取消／未到店、手動預約、現金收款與實收統計。
- iPhone 私人行事曆單向訂閱：每位管理員可獨立開啟、停用或重設連結，預約變更仍在後台進行。
- 客人歷次服務與優惠資格核對；同行霧眉以關聯碼安排兩筆預約。
- LINE 推播佇列、重試、額度查詢、發送狀態與前一天提醒排程。
- CSV 匯出（防試算表公式注入）、操作紀錄、機密掃描、GitHub Actions CI/CD。
- 獨立示範模式：`/#demo-booking`、`/#demo-admin`、`/#demo-my`。資料僅存於當前瀏覽器記憶體，重新整理重置，不會發送 LINE。

## 技術與費用

React + TypeScript + Vite；Cloudflare Worker 同時提供靜態網站與 API；D1 儲存資料。使用 Cloudflare 與台灣 LINE 官方帳號免費額度起步，無須付費網域。LINE 推播每月免費額度有上限；提醒預設關閉，正式上線需監控平台用量。不是無限量免費。

## 本機開發

```sh
npm ci
npm run build
npm run db:local
# 複製 .env.example 為 .dev.vars；只在本機／私人平台填值
npm run worker:dev
```

另開終端執行 `npm run dev`。Vite 把 `/api` 代理到本機 Worker 8787 埠。設計示範不需 LINE 憑證，可直接開啟示範網址。

```sh
npm run check
npm run test:ui
npx wrangler deploy --dry-run --outdir .deploy/worker-check
```

## 正式啟用

請依 [部署指南](docs/DEPLOYMENT.md) 完成 Cloudflare D1、LINE Channel、管理員白名單與 GitHub 設定。已依店家提供的範圍，以接睫 120 分鐘、補睫 60 分鐘、卸除 30 分鐘、霧眉 180 分鐘及整理 30 分鐘設定初始值。接睫、霧眉先採上限，店家可在後台依款式調整。霧眉補色 180 分鐘、無創除色 60 分鐘、下睫毛加購增加 30 分鐘，均已確認。補色同樣採店家提供範圍的上限。營業時間與地址尚待設定，初始不開放預約。示範中的日期排班不可作為正式排班。

後台新增預約直接成立，不需再次審核；已綁定 LINE 的現有客人會排程確認通知。未綁定 LINE 時，新增成功畫面自動產生邀請連結與訊息，可複製後私訊給客戶；也可在既有預約視窗重新產生。登入 LINE 後須核對並確認，才會綁定此筆預約。邀請最長有效 7 天且不得晚於服務開始，預約取消或逾時亦無法使用；重新產生會撤銷舊連結。連結視同憑證，請勿公開分享。通知只有 LINE API 受理紀錄，不保證送達或已讀。客戶自行申請同行優惠需先建立兩位關聯預約才可確認；後台直接確認時由管理員核對同行安排；其中一位取消時由店家處理優惠。補睫依前次已完成服務核對，金額由店家確認。無創除色 NT$2,000–3,000，正式審核時確認價格。

## CI/CD

- `ci.yml`：PR 與 main push 執行機密掃描、核心邏輯與瀏覽器測試、TypeScript／前端建置及 Worker dry-run。
- `deploy.yml`：main push 或手動觸發；僅在 `DEPLOY_ENABLED=true` 時執行。重新通過檢查後套用 migration 與部署，使用 production environment 的 GitHub Secrets。
- 工作流程只讀 repository、釘選 action commit，PR 檢查不注入 production 金鑰。不使用 `pull_request_target` 執行外部程式。
- 套用的 migration 不可修改歷史；後續變更新增 migration。部署失敗不會自動復原已套用的資料庫結構。

## 資料與安全

見 [SECURITY.md](SECURITY.md) 與 [操作手冊](docs/OPERATIONS.md)。`.dev.vars`、`.env`、本機資料庫、匯出、備份、部署設定與私鑰均忽略；請保持 GitHub 公開專案只存程式碼和公開素材。

品牌素材由店家提供，保留原檔，未宣告開源授權。原始碼未指定開源授權；公開可瀏覽不等於授權他人使用品牌或再發佈。

## 載入與登入體驗

登入狀態確認前顯示全畫面等待提示。「我的預約」與後台首次取得資料前不顯示空清單或 0 筆統計；重新查詢保留原有資料，失敗顯示重試，查詢成功才顯示空狀態。LINE 額度獨立顯示等待與重試，請求超過 15 秒提示逾時。LINE OAuth 失效、取消或失敗會返回網站顯示登入提示；登入狀態過期時可在原頁重新登入。

後台入口僅對已登入且在管理員白名單內的使用者顯示於選單及頁尾，移除公開示範後台連結。這是畫面顯示規則，後端仍逐次驗證管理員權限。

首頁四款美睫使用 image gen 產生的款式示意圖，以 WebP 提供；原始生成檔保留於工作區，網站標示為示意圖，不作為店家實際施作照片。

首頁聯絡區與各頁頁尾提供店家的 LINE 官方帳號、Instagram、Facebook、Threads 連結。須知、活動及價目以網站內容呈現，參考公告與價目表圖片不再隨網站發布。

指定新預約審核通知對象時，在私有 D1 的 `notification_recipients` 設定 `kind=review_requested` 與完整 `user_id`。該帳號必須在 `ADMIN_LINE_USER_IDS` 白名單內；未設定時不會通知其他管理員。此設定不可放入公開 Git 或資料遷移檔。
